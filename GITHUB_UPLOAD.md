# Upload this assignment to GitHub

This is a separate project from Space Invaders. Give it its own repository.

1. Open GitHub Desktop and choose **File → Add Local Repository**.
2. Select `/Users/patriciolandeta/CS111 Code/Tower-Defense-Assignment`.
3. If Desktop says the folder is not a Git repository, choose the option to create a repository there. Keep the existing project files and `.gitignore`.
4. Review the changes, enter `Complete Neon Bastion tower defense assignment`, and click **Commit to main** if a commit is needed.
5. Click **Publish repository**. A suitable name is `neon-bastion-tower-defense`.
6. Choose the visibility your instructor requires, then publish.
7. Open **View on GitHub** and submit that repository link. A private repository requires inviting the instructor as a collaborator; a public repository is readable through its link.

Include `Assets` and every `.meta` file, `Packages`, `ProjectSettings`, and the project documentation. Unity's generated Library and cache folders are excluded automatically. Do not replace the existing Space Invaders repository.

The README explains exactly which scene and editor version to open. `ASSIGNMENT_NOTES.md` maps the rubric to the implementation, and `VALIDATION.md` describes the tests.
